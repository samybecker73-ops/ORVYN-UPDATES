# ORVYN — Official Windows Updates

This public repository distributes official ORVYN Windows releases through GitHub Releases.

## Update channel

- Stable channel: `latest`
- Release assets are generated by the ORVYN source repository build workflow.
- Do not upload or edit `latest.yml` manually. It is generated by electron-builder and must match the installer and blockmap from the same release.

## Expected release assets

Each Windows x64 release should include:

- `ORVYN-Setup-<version>.exe`
- `ORVYN-Setup-<version>.exe.blockmap`
- `latest.yml`

The application downloads update metadata and installers from this public repository. No publishing token is stored in the application or this repository.

## Security

Only the ORVYN source repository's GitHub Actions workflow should publish releases. The publishing token should be stored as a GitHub Actions secret in the source repository and scoped to this repository with Contents read/write permission.
